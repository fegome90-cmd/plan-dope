# Enterprise Planning Examples

This directory contains complete example files for the enterprise-planning plugin.

## Files

| File | Description | Phase |
|------|-------------|-------|
| `requirement-set.yaml` | Complete RequirementSet with claims, assumptions, constraints | Phase 1 |
| `strategy-evaluation.yaml` | Strategy comparison matrix with scores | Phase 2 |
| `plan-tree.yaml` | Hierarchical decomposition (Vision → WOs) | Phase 3 |
| `work-order.yaml` | Complete WorkOrder with DoD, scope, dependencies | Phase 4 |
| `validation-report.yaml` | Validation results output | Phase 5 |

## Usage

These examples demonstrate:
- Proper YAML schema structure
- Required vs optional fields
- Best practices for each phase
- Realistic complexity (not toy examples)

## Reference in Documentation

SKILL.md files reference these examples with:
```
[See: examples/plan-tree.yaml for complete example]
```
